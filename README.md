## bookstore-backend

A Spring Boot application developed incrementally through multiple Use Cases(UC). Each use case is implemented in a separate Git branch to demonstrate the progressive development of the application

## Project Overview

This project repo is the backend part of my FullStack Project, Bookstore Application. 

## Branch Structure

| Branch | Description | 
|---|---|
| main | Default branch of the repo consisting of the README.md file
| develop | Contains the initial project structure and integrated development changes |
| feature/UC1-ProjectSetup | Sets up the initial bookstore backend application structure and connecting the backend with the frontend application |
| feature/UC2-UserAuthentication | Adds user authentication function in the application |
| feature/UC3-BookManagement | Added function to add book product and delete or edit book information |
| feature/UC4-RoleBasedAuthorization | Separated Admin and User functionality and authorization |
| feature/UC5-BookBrowsing | Added feature to browse book such as filter |
| feature/UC6-ShoppingCart | Adds Shopping cart feature |
| feature/UC7-Wishlist | Adds Wishlist features |
| feature/UC8-CustomerDetails | Enables user to add their personal contact information and delivery address |
| feature/UC9-Order | Enables user to place order and for admin to manage them |
